# Villanova 3D Recreation

Procedural Three.js recreation of Villanova University campus in the dark architectural-maquette style (sibling to [Pittsburgh-3D-Recreation](https://github.com/aditano/Pittsburgh-3D-Recreation)).

OSM buildings, paths, landmarks. Opens in the browser. Not official Villanova CAD or photogrammetry.
